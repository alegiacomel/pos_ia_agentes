# Prompts do Professor

Textos com os Prompts que o Professor utilizou na disciplina "Criação de Agentes Autônomos".

Comandos que o Professor possa ter inserido fora dos vídeos não estão contemplados.

## Estrutura

As linhas que contêm somente "-" (hífem) são separadores dos prompts.

Linhas com "***" (3 asterísticos) São comentário do fonte,servem para auxiliar. Não digitar.

Os módulos estão identificados.

## Módulos

No módulo 1 foi criado o projeto "notas API", devido a isso está [em arquivo distinto](./prompts_professor/conversa-notas-api.txt).

O projeto principal (módulo 2 até módulo 9) está no [arquivo do projeto Ops Pilot](./prompts_professor/conversa-ops-pilot.txt)
